# 🎮 Tic Tac Toe Deluxe

A vibrant, modern, and smart Tic Tac Toe game built using pure HTML, CSS, and JavaScript with zero external libraries or APIs.

## ✨ Features

- **🎮 Two Game Modes:**
  - **2 Players (Pass & Play):** Local multiplayer on the same device.
  - **vs Computer (AI):** Powered by the **Minimax Algorithm** (optimal and unbeatable) or Casual mode.
- **🎨 Bright & Colorful Theme:**
  - Dynamic fluid gradient backgrounds.
  - Glowing neon marks (Coral Red for X, Electric Cyan for O).
  - Glassmorphic card interface with smooth pop animations.
- **🎉 Confetti Explosion:**
  - Custom canvas-based confetti particle celebration engine upon winning.
- **🎵 Built-in Synthesizer Sound Effects:**
  - Real-time sound effects generated using the native browser **Web Audio API** (moves, victory chimes, draw sound) — zero audio file dependencies.
  - Sound mute/unmute toggle.
- **📊 Real-time Score Tracker:**
  - Tracks Player X wins, Player O / Computer wins, and Stalemate ties.
- **📱 100% Mobile Responsive:**
  - Adapts seamlessly to smartphones, tablets, and desktop displays.

## 🚀 Live Demo with GitHub Pages

To play directly in your browser:
1. Go to your repository **Settings** > **Pages**.
2. Under **Build and deployment**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/ (root)`, then click **Save**.
4. Your game will be live at: `https://ishtiyaq8811.github.io/tic-tac-toe/`
